# R6 真人试玩协议（仅材料准备）

模式分层：Fake 试玩验证界面、规则和确定性产品流程；真实导师试玩验证真实模型语言体验。二者不得混合归因。当前只完成方案和真实模式离线装配，尚未联系或执行任何真人试玩。

状态：材料已准备，未联系任何人，未执行试玩。第一轮建议 3～5 人，仅作可用性探索，不宣称统计显著性或用户收益。

## 招募与知情说明草稿

这是本地架空游戏原型试玩。参与自愿，可随时退出并要求删除记录；不提供现实医疗建议。只记录任务完成、界面困惑、1～5 分主观评价及自愿反馈，不收集身份证、真实医疗信息、API Key、无关聊天、私人文件画面或不必要联系方式。

## 任务卡

- 15 分钟：进入医馆、理解弟子身份、完成一个病例、查看师评成长、评价导师是否像导师。
- 45～60 分钟：至少完成三个基础病例，体验补课或考试、传承拒绝或授予，并观察跨病例记忆和教学变化。

## 观察记录与问卷

记录能否开始、是否知道下一步、是否理解课程/能力/关系/考试/传承解释、导师是否记得玩家、提示量、是否代替玩家解题、是否愿意继续及三个最困惑处。理解度、导师可信度、记忆感、成长感、继续意愿均用 1～5 分，并保留自由文本原因。

## 严重度、保存与删除

无法开始、不理解操作、存档丢失、答案泄漏、导师代行动、成长关系解释错误、跨玩家泄漏或考试传承状态错误，任一即阻塞发布。原始记录使用随机参与编号、仅本地加密/受限目录保存；脱敏总结不含可识别信息。退出请求或项目结束后删除原始联系方式与原始录屏，保留期限由执行授权前明确，未授权前不创建真实记录。

结束访谈询问：最清楚/最困惑的环节、导师可信或不可信的原因、何时感到被记住、课程安排是否可解释、提示是否越界、是否愿意继续及最希望改进的一点。
