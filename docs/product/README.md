# 产品文档

《异闻行录》是 Human-Agent Cooperative Game NPC：玩家与自主 NPC 组成调查搭档，共同处理六个古风志怪异案。第一次游玩请直接阅读根目录 [`START_HERE.md`](../../START_HERE.md)。

M1–M5 是现行 Cooperative GameNPC 的工程与评测主线；M4.5 语义材料仅作为当前长期记忆检索的回归依据保留。

当前实现按模块阅读请从[架构目录](../architecture/README.md)进入；案件、协作运行时、Planning/行动契约、Context、Memory、Reflection 与 Evaluation 均有独立主文档。
