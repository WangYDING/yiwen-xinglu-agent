# 产品路线

## 已完成

- 六个志怪异案和本地 Web 入口；
- Human-Agent Cooperation；
- Goal、Plan 与 Replanning；
- 玩家隔离的长期记忆与语义检索；
- 结果驱动 Reflection；
- 确定性 paired benchmark 与受控真实模型小样本复核；
- MCP、本地持久化、事件回放和失败恢复。

## 当前维护重点

1. 保持六案内容、公开视图和规则状态的一致性；
2. 改善 Cooperative GameNPC 的可解释规划与玩家影响可见性；
3. 用现有 M4.5 Gold/Holdout 防止语义检索回归；
4. 扩充《异闻行录》自己的场景与真人试玩证据；
5. 保持本地优先、最小权限和可审计边界。

## 明确不做

- 修习、课程、补课、考试、传承；
- 师徒关系或能力成长门禁；
- LLM 直接修改世界状态；
- 未经授权的真实模型或外部数据调用；
- 在缺少样本时宣称统计成功率或玩家收益。
