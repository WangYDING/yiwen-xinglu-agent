# R5 六病例与本地医馆产品

R5 已把既有三病例、三个进阶病例、教学计划、规则考试、权限和“溯契还因”组合成同一个普通用户入口。`ClinicService` 只编排既有权威应用服务，不保存新的权威状态；各类状态仍分别按原有事件与存档回放。

六病例固定顺序为：旧纸伞、灰灶、月井、双灯巷与相悖证词、雾渡客船与借寿灯、归契古祠与无名碑。课程选择 v2 先处理未解决补课，再完成基础课与考试，随后推荐三个进阶病例；它不锁关，也不让模型决定课程。

本地网页仅绑定 `127.0.0.1`，使用标准库服务端渲染，不访问 CDN，不运行真实模型，不开启语义记忆。所有写入经正式应用服务，POST 具有操作令牌，玩家文本经过 HTML 转义；公开组合视图不含根因、正确标记、考试答案、秘密权限、Prompt、密钥或内部路径。

归契古祠始终可走普通调查并获得满分。获得传承后，玩家可用等价公开调查替代一次普通旧拓片核对；完成任一条路径即满足同一个 Schema 调查要求，不会继续把另一项显示为必做。它不自动辨证或处置，不改变隐藏真相、评分与满分。六病例是 v1.0 内容完成线；R6 仍在进行中。
