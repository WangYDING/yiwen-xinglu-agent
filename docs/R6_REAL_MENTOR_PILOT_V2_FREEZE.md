# R6 真实导师 Pilot v2 冻结

v2 仅替换 v1 无法执行的供应商身份和专用请求封装，不改四个场景主题、公开/隐藏边界、期望、课程、考试或传承决定。v1 的网络前停止、`not_observed` 与零费用结论永久保留。

固定供应商为 DeepSeek，模型 `deepseek-v4-flash`，thinking `disabled`，`response_format=json_object`，非流式，`max_tokens=512`，30 秒超时。价格使用 `deepseek_v4_flash_mentor_pricing_2026_08_13`，总预算精确为 `0.05 CNY`。

四场景共有五个基础请求：初课提示、错误诊断补课、考试失败解释各一；传承场景包含同一玩家的拒绝状态与授予状态两个子请求。每个基础请求最多一次公开契约修复，禁止整轮重跑。

冻结资源内分别记录公开输入、期望与配置的规范化 SHA-256。真实执行只把公开输入与允许动作发送给供应商，期望和禁止词只供本地确定性评测。
