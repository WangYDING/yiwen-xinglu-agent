## 2. 研究问题

- **RQ1**：在相同模型、病例、工具和安全过滤下，基础向量记忆与多因素记忆/自适应教学能否提高长期任务成功率？
- **RQ2**：多因素排序能否提高关键记忆的 Precision、Recall 与 F1，并降低错误记忆率？
- **RQ3**：自适应课程能否提高课程匹配度并减少难度偏差？
- **RQ4**：在隔离合成环境中，程序化权限过滤相对仅提示词保密能降低多少泄漏风险？
- **RQ5**：能力增益带来的真实 Token、延迟和成本变化是多少？
- **RQ6**：工具失败、对抗输入和状态冲突下，系统是否仍保持合法状态和可恢复性？

## 3. 研究假设与目标

- **H1**：V2 的端到端任务成功率可能高于 V1；“绝对提升 10 个百分点”是待检验的研究目标，不是工程完成条件。
- **H2**：V2 的记忆 F1 可能高于 V1，错误或虚构记忆比例可能更低。
- **H3**：V2 的课程选择质量可能高于使用固定课程的 V0/V1。
- **H4**：隔离 A4 中，启用程序化过滤的安全配置可能比仅提示词保密对照具有更低泄漏率。H4 不比较不安全产品 V0 与安全 V1/V2。
- **H5**：V2 的真实 Token 与 P95 延迟增幅应在 Pilot 后设定可接受目标；当前不预填结果。
- **H6**：所有产品版本的关键状态非法写入和会话串扰都应为 0。

除 H6 的安全底线外，数值均为研究假设或优化目标。没有达到预期增益时，应保留并报告负结果，而不是把它解释为工程未完成。

## 4. 产品版本边界

三个产品版本共用：

- 相同基础模型和采样配置；
- 相同确定性病例引擎、工具 Schema 和最大步骤；
- 相同 `AgentAction` 与 `EpisodeResult`；
- 强制开启的 `AgentContextFilter`；
- 模型不得直接修改病例、关系、能力、权限、技能或永久记忆。

| 能力 | V0 | V1 | V2 |
|---|---|---|---|
| 上下文 | 最近 K 条消息 | 最近消息 + 长期记忆 | 最近消息 + 长期记忆 |
| 长期记忆 | 无 | 基础向量 Top-K | 多因素排序 |
| 课程 | 固定顺序 | 固定顺序 | 自适应课程 |
| Reflection | 无 | 无 | 有 |
| `AgentContextFilter` | 强制 | 强制 | 强制 |
| 结构化行动与规则工具 | 有 | 有 | 有 |

### V0：安全 Prompt-Only Fixed Curriculum

- 仅使用最近 K 条对话；
- 不读取或写入长期记忆；
- 使用固定课程；
- 使用程序化过滤后的玩家、病例和公开候选视图；
- 使用结构化工具循环、规则拒绝、有限修复和降级；
- 不进行 Reflection。

“Prompt-Only”只表示不含长期记忆、自适应规划和 Reflection，不表示关闭程序化安全过滤。

### V1：Vector Top-K Memory + Fixed Curriculum

- 在 V0 上增加基础向量相似度 Top-K 长期记忆；
- 保持固定课程；
- 不使用多因素排序、自适应教学或 Reflection。

### V2：Multi-Factor Memory + Adaptive Curriculum + Reflection

- 使用相关性、重要性、时间新近度等多因素记忆排序；
- 使用经过验证的玩家能力状态进行自适应教学；
- 使用结构化 Reflection；
- 所有写入仍由领域事件和确定性投影产生。

## 5. A4 隔离安全消融

A4 是安全研究夹具，不是 V0/V1/V2 产品配置。仅提示词保密的对照必须同时满足：

- 只使用合成病例、合成秘密和无真实用户数据；
- 在独立进程和临时状态中运行；
- 禁用持久化、永久记忆、网络副作用和外部动作；
- 不连接生产或演示存档；
- 标记 `production_eligible = false` 与 `deployable = false`；
- 运行结束后销毁临时状态；
- 结果只用于安全对比，不产生可部署配置。

A4 成功判据是能够量化两种安全机制的泄漏差异，并证明隔离边界有效；不是要求任何产品版本关闭过滤。

## 8. 指标

### 工程验收指标

- 全部测试可在全新环境复现；
- 关键状态非法写入次数为 0；
- 会话间状态串扰次数为 0；
- 每个成功 Episode 的事件连续且可重放为相同终态；
- Schema、错误、重试、降级和工具日志完整；
- 配置、Prompt、数据和结果具有版本或哈希；
- 不存在伪造的延迟、Token、成本或成功率。

这些是工程发布门槛，不依赖 V2 必须比 V1 提升某个百分比。

### 研究指标

- 端到端任务成功率；
- 工具选择与参数准确率；
- JSON/Schema 首次通过率和修复率；
- 记忆 Precision、Recall、F1 与 False Memory Rate；
- 课程选择质量与难度偏差；
- 安全泄漏率；
- 故障恢复率和最大步骤耗尽率；
- 实测延迟 P50/P95、输入/输出 Token 和成本。

缺失指标保持缺失，不使用估计值冒充实测值。

## 9. Episode 成功判定

产品 Episode 同时满足以下条件才计为成功：

- 在最大步骤内达到结构化目标；
- 模型输出首次通过 Schema 或在唯一一次有界修复后通过；首次通过不因“没有发生修复”被判为失败；
- 工具参数和状态变化通过规则层；
- 最终事件连续且可重放；
- 没有非法关键状态写入或会话串扰；
- 没有泄露不在安全视图中的信息；
- 轨迹和必要日志完整。

安全判据对 V0、V1、V2 相同。V0 不因是基线而允许关闭过滤。
