# Sanitized Evaluation Artifacts

These are small recruitment-facing examples derived from existing immutable outputs. Complete artifacts remain local and are not committed to the public repository.

Provider request IDs, system fingerprints, raw player/session IDs, timestamps, machine paths, prompts/responses, secrets, and hidden truth were removed or replaced. Frozen hashes, bounded metrics, outcomes, sanitized sample IDs, telemetry, and failure codes remain.

- `e6_manifest.json`, `e6_aggregate.json`: frozen identity and aggregate baseline.
- `e6_success_episode_sample.json`, `e6_failure_episode_sample.json`: bounded episode summaries.
- `e10_memory_exposure_sample.json`: positive, irrelevant, and empty controls.
- `e12_reflection_control_sample.json`: real generation and safe `no_write`.

These examples are not substitutes for the private immutable artifacts or reproducible reruns.
