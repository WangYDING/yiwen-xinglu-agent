## 2. 人工内容边界

逐条核对 15 个查询和 60 个候选后确认：

- 全部为架空、合成、公开文本；没有真实玩家姓名、真实聊天、真实医疗信息、密钥或机器隐私；
- 没有 `root_cause`、`valid_diagnosis_ids`、`diagnosis_correct`、正确处置标记、隐藏门槛或评分内容；
- 错误诊断候选由既有确定性投影写成“玩家提交过公开假设”，没有提升为世界事实；
- 提示注入句只出现在候选记忆数据中，不进入系统消息、工具定义、检索作用域或 Gold 配置；
- 其他玩家、当前 Episode、失效和硬删除候选只用于验证检索前过滤；
- 更正和极短文本候选通过可信生命周期边界形成，不给 Agent 增加永久记忆写入口；
- 较长文本是接近项目 `4096` 字符上限的公开查询，不突破权威记忆内容自身 `2000` 字符契约。正式运行固定 `max_length=512 Token`，会记录 tokenizer 截断前后 Token 数；二者不是 512 字符。

## 3. 预注册运行规则

- 模型固定为 `BAAI/bge-m3@142964af7e05de16511657561de8e8750fc153a0`；
- 空间固定为 `bge_m3_142964af7e05_dense_fp32_d1024_cuda_l512_v1`；CUDA、FP32、1024 维、batch size 8、离线加载和 socket 网络阻断；
- ranking 视图固定 `top_k=3, min_similarity=-1.0`，稳定顺序为 `similarity DESC, memory_id ASC`；
- 空结果阈值网格固定为 `0.20` 至 `0.80`、步长 `0.05`；只用 5 条 calibration，依次最大化空结果正确率、calibration macro F1，再选择更高阈值；
- test 的 10 条场景只接受 calibration 选出的阈值，不参与选择；
- 向量重复性最大逐元素绝对差容差固定为 `1e-6`；
- 第一次正式运行失败即停止；不运行补救或第三次，不改 Gold、阈值、Top-K、查询或文本。

Gold 预期只由评测器加载。Adapter、Retriever、QueryBuilder、`AgentContextFilter` 与 Prompt 只接触输入文件产生的公开数据，不接触相关集合、禁止集合或空结果真值。
