# M4.5 语义 Memory 实验总结

## 目的与结论

M4.5 验证本地 BGE-M3 Dense Embedding 是否适合作为《异闻行录》长期 Memory 的语义检索层。实验覆盖本地模型接入、权限与生命周期隔离、冻结数据评测、重复性检查和失败分析。

最终状态为 `closed_with_known_dense_retrieval_limitations`：

- 本地模型接入、向量契约、安全隔离和重复性通过；
- Dense-only 排名达到主要 Top-K 门槛；
- 保守返回策略漏召回较多相关记忆，更正场景仍有漏召回；
- 本轮结果没有获得将实验检索直接接入 Agent 决策的准入证据；
- 这些指标不代表真实玩家收益或生产准确率。

## 实验对象

| 项目 | 冻结值 |
|---|---|
| 模型 | `BAAI/bge-m3` |
| Revision | `142964af7e05de16511657561de8e8750fc153a0` |
| 表示 | Dense、FP32、1024 维、L2 归一化 |
| 运行方式 | 本地离线加载，`local_files_only=True` |
| 网络与费用 | 无外部 Embedding API；正式本地评测费用为 0 CNY |
| 权威记忆 | SQLite 中的已提交公开事件 |
| 向量数据 | 可重建的派生索引，不取代权威事件 |

模型只从固定白名单文件加载，并验证输出数量、顺序、维度、有限值和非零范数。模型文件保存在 Git 忽略的 `runtime_models/`，不进入 Git、wheel 或 sdist。

## 安全边界

候选记忆在向量排序前完成确定性过滤：

- 玩家隔离；
- 当前 Episode 隔离；
- 生命周期状态过滤；
- superseded、invalidated 和已删除内容过滤；
- 公开内容白名单；
- Embedding 空间身份隔离。

实验检索不能修改案件状态、玩家状态、工具集合或权威 Memory。失败不会伪装为空历史，也不会覆盖现有的结构化状态路径。

## 数据与协议

第一版开发集包含 15 条查询和 60 条候选。首次正式运行发现评测契约将“合法语义负例”和“必须在候选阶段排除的安全对象”复用了同一标签，因此安全汇总被错误触发。该次运行停止且未被包装为模型结果。

修正后的评测器保留原始输入，将候选明确分为：

1. 相关记忆；
2. 合法语义负例；
3. 因权限或生命周期必须排除的对象。

开发集随后只用于失败诊断，不再用于证明改进通过。新的 Holdout 在运行前冻结，包含 36 条查询和 144 个候选，并固定：

- 输入和期望结果；
- calibration/final-test 划分；
- Top-K 与阈值选择规则；
- 指标分母；
- 安全分区；
- 模型、表示空间和运行配置。

冻结数据位于 `tools/experiments/data/evaluation/`，字节身份由 `tests/test_project_layout.py` 中的 SHA-256 回归检查保护。

## 最终结果

唯一一组两次正式本地运行均完整结束，两次有序结果、向量载荷、策略和指标一致，最大逐元素差为 `0.0`。

| 指标 | 结果 | 判定 |
|---|---:|---|
| Recall@1 | `0.90` | 通过主要排名门槛 |
| Recall@3 | `1.00` | 通过主要排名门槛 |
| MRR | `0.975` | 通过主要排名门槛 |
| FP | `0` | 未返回普通无关项 |
| Irrelevant retrieval rate | `0/11` | 通过 |
| TP / FN | `11 / 11` | 召回门禁过于保守 |
| Micro F1 | `0.6666666667` | 未达到 `0.80` 准入线 |
| 更正场景 FN | `1` | 未达到必须为 `0` 的准入线 |

跨玩家、当前 Episode、失效内容、删除复活、隐藏信息泄漏、Prompt 边界改变、权威记忆修改、空间混用和索引状态伪装等安全计数均为 `0`。

## 失败分析

主要问题不是 Top-K 排名，而是排名后的保守返回门禁：它避免了普通 false positive，却同时过滤了较多相关项。简单调整阈值或扩大 Top-N 不能同时解决召回与更正场景问题。

早期检索文本还存在表示不对称：查询包含较长的病例背景和结构字段，部分正确记忆较短，而无关候选共享模板文本。后续版本将向量查询限制为明确检索意图和已发现的公开线索，并为查询与文档表示建立独立版本身份。新 Holdout 仍未达到完整准入线，因此没有继续通过更换模型、增加 reranker 或扩大题库来追逐通过结果。

## 产品影响

本实验保留了以下工程成果：

- 固定模型身份和离线加载契约；
- 版本化查询与文档表示；
- 玩家、Episode、生命周期和向量空间隔离；
- 冻结数据、不可混合结果与重复性检查；
- 失败安全和可审计的负面结果。

它没有证明：

- 真实 Agent 会正确使用召回内容；
- Memory 能提高任务成功率；
- 模型能抵抗 Memory 文本中的提示注入；
- 系统具备生产规模性能或并发事务保证。

当前产品使用相同的安全过滤和模型身份作为回归依据，但任何面向 Agent 的语义 Memory 暴露必须由独立的当前评测证明，不能引用 M4.5 的合成结果替代。
