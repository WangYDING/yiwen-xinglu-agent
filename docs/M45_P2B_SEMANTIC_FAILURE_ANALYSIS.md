# M4.5-P2b 离线语义失败根因分析

## 1. 结论冻结

以下历史结论保持不变：

1. M4.5-P2 工程、安全与重复性通过；
2. 语义质量未通过；
3. test Recall@3 为 `0.8888888889`；
4. test 在阈值 `0.65` 下返回 13 条合法记录，其中 5 条是合法但无关的语义 FP；
5. 所有安全计数为 0；
6. 原 15 条场景从本检查点起是“已观察开发/诊断集”，不能再次作为独立 test 证明新策略有效。

没有降低门槛、修改 Gold 标签、删除场景或重写 P2 结论。M4.5-P3 和 M5 仍未开始。

## 4. 5 个 test FP 与 1 个 test FN

### 4.1 `semantic_correction_001`：2 FP + 1 FN

- FP：`cand_correction_2`，0.662104；
- FP：`cand_correction_3`，0.654114；
- FN：正确替代记忆 `cand_correction_1`，0.632996，完整排名与合法排名均为第 4；
- 第三个无关项 `cand_correction_4` 为 0.645599，低于 0.65，未成为正式 FP。

正确更正文本只有“经可信更正：学徒最终把银叶交给守桥人”。三个负例则带有完整投影模板：“在病例……中，玩家完成公开调查……(inspect_object)，新发现：未发现新线索”。查询也是包含版本、当前消息、病例标题、通用简介、线索数组和固定课程的长 JSON。短更正文本与模板化长记忆之间存在明显表示不对称：正确实体虽然出现，但共享模板给三个无关长文本提供了更大的共同表示底座。

这是唯一 test FN。任何 `Top-1/2/3` 或更高阈值都无法把合法排名第 4 的正确项召回；必须改变检索文本表示或增加能改变候选顺序的第二阶段。

### 4.2 `semantic_prompt_injection_data_001`：1 FP

- 正确项：`cand_prompt_injection_data_1`，0.713269；
- FP：`cand_prompt_injection_data_3`，0.653236，仅比阈值高 0.003236。

查询中的“伞面”“字样”与负例中的“破伞骨”产生局部词汇重合，再叠加所有调查记忆共有的模板，使该负例越过绝对阈值。它是普通语义 FP，不是 Prompt 边界违规；系统指令、工具和 Schema 均未改变。

### 4.3 `semantic_mixed_language_entity_001`：2 FP

- 正确项：`cand_mixed_language_entity_1`，0.751464；
- FP：`cand_mixed_language_entity_4`，0.675312，匹配“冷/芦”局部概念；
- FP：`cand_mixed_language_entity_3`，0.664709，匹配 `moon`；
- `cand_mixed_language_entity_2` 也有 0.661043，但因 Top-3 截断未返回。

同一查询同时包含 `moon-reed`、月芦、`cold glow`。负例只覆盖部分实体或相邻概念也能超过全局绝对阈值，说明“是否完整匹配复合实体关系”不能仅由 0.65 判断。

## 5. 其他重点失败机制

### `semantic_short_text_001`

正确文本只有“守约。”，分数 0.509447、排名第 4。三个模板化负例分别为“失约。”0.680751、“赴约。”0.676144、“守门。”0.665747。短正确项缺少模板上下文；负例既有长模板，又分别拥有“约”或“守”的局部字面重合。模型没有在这个表示下可靠区分“守约”和含义相反的“失约”。该场景属于 calibration，不计入 test FN，但与更正场景共同证明表示长度和模板不对称是系统性风险。

### `semantic_lexical_distractor_001`

相反行为诱饵 `cand_lexical_distractor_2` 含“月井回声、水面、涟漪”，以 0.682341 排第 1；真正的“避免惊动”通过“噤声、绕开井沿”间接表达，只得 0.611513。Dense 相似度更偏向名词和场景词重合，没有可靠表达“故意敲击”与“避免惊动”的逻辑反向关系。

### 查询与文档公共模板

`memory_query_v1` 的所有查询都重复以下字段或内容：

- `version`、`current_user_message`、`case_title`、`case_synopsis`、`discovered_clue_descriptions`、`fixed_lesson` 等 JSON 字段名；
- “这是仅含公开架空信息的跨 Episode 记忆检索探针”；
- “固定课程：先核对当前公开信息，再选择合法行动”。

大多数权威记忆投影文本重复：

- “在病例……中，玩家完成公开调查”；
- 动作类型 `(inspect_object)`；
- “新发现：未发现新线索”。

空结果场景的无关记录仍得到 0.555–0.595，其他无关记录大量聚集在 0.60–0.68。相关项分数与负例分数明显重叠：test 最低相关分为 0.632996，而 test 最高合法负例为 0.675312。现有向量可以证明重叠存在，但不能在不重新编码消融文本的情况下定量归因“某个模板贡献了多少分”；模板噪声是有直接文本证据支持的根因假设，仍需新版本开发集和未见 holdout 验证。

## 6. 事后反事实分析

本节所有结果均为 **`post_hoc_exploratory_only`**。它们使用已经观察过的 test 分数，只能产生假设，不能改变 P2 失败结论或证明新策略通过。

| 策略 | TP/FP/FN | Precision | Recall | F1 | irrelevant retrieval rate |
|---|---|---:|---:|---:|---:|
| Top-1，无阈值 | 8/2/1 | 0.8000 | 0.8889 | 0.8421 | 2/10 = 0.2000 |
| Top-2，无阈值 | 8/12/1 | 0.4000 | 0.8889 | 0.5517 | 12/20 = 0.6000 |
| Top-3，无阈值 | 8/22/1 | 0.2667 | 0.8889 | 0.4103 | 22/30 = 0.7333 |

| 历史阈值 0.65，最多 3 | 8/5/1 | 0.6154 | 0.8889 | 0.7273 | 5/13 = 0.3846 |
| 阈值 0.70，最多 3 | 3/0/6 | 1.0000 | 0.3333 | 0.5000 | 0/3 = 0 |
| 阈值 0.75，最多 3 | 1/0/8 | 1.0000 | 0.1111 | 0.2000 | 0/1 = 0 |
| 阈值 0.65，最多 1 | 8/1/1 | 0.8889 | 0.8889 | 0.8889 | 1/9 = 0.1111 |
| 阈值 0.65，Top-1 分差 ≥0.01 | 8/0/1 | 1.0000 | 0.8889 | 0.9412 | 0/8 = 0 |
| 阈值 0.65，Top-1 分差 ≥0.02 | 8/0/1 | 1.0000 | 0.8889 | 0.9412 | 0/8 = 0 |
| 阈值 0.65，Top-1 分差 ≥0.03 | 7/0/2 | 1.0000 | 0.7778 | 0.8750 | 0/7 = 0 |
| 阈值 0.65，Top-1 分差 ≥0.05 | 6/0/3 | 1.0000 | 0.6667 | 0.8000 | 0/6 = 0 |

结论：

1. **单纯提高绝对阈值不能同时保留召回并清除 FP。** 0.70 虽把 FP 降为 0，却把 FN 从 1 增加到 6；相关与负例的分数区间有交叠。
2. **单纯 Top-1 不能修复更正记录。** 它减少 FP，但仍选择 correction 的错误第一名，正确更正项继续是 FN。
3. **分差门禁在已观察数据上看似有效，但不是验证证据。** 0.01/0.02 恰好去掉观察到的 FP，仍漏掉 correction；这些数值不能直接带入产品或新 test，必须在新的 calibration 上从预注册网格选择。
4. **至少需要改变检索用文本表示，或者使用能改变顺序的第二阶段重排。** 阈值、Top-N 和分差只能裁剪现有顺序，不能把 rank-4 正确项提升进 Top-3。

## 7. 最小改进建议

### A. `retrieval_query_v2`——推荐

为 Embedding 单独构造最小公开查询，只保留当前用户检索意图和已经发现、与检索意图直接相关的公开线索。病例通用简介、固定课程、JSON 字段名不进入向量文本；它们仍可完整保留在 Agent 最终 Prompt。查询版本、字段顺序、规范化和长度上限必须冻结。

### B. `embedding_document_v2`——与 A 一起推荐

不修改 SQLite 权威记忆原文。增加可重建的派生 Embedding 文本，只保留公开事件事实、公开结果和必要的更正语义，减少“在病例中”“玩家完成公开调查”“未发现新线索”等所有文档共有的模板噪声。更正文本与普通事件使用一致的、但能明确表达“当前有效替代”的结构；错误诊断继续只描述“玩家曾提交该假设”，不能升级为世界事实。

派生文本必须有独立版本和哈希，并进入新的 `embedding_space_id`；现有 BGE/Fake 向量都不覆盖。权威记忆、来源链、更正、失效、硬删除和玩家隔离规则完全不变。

### C. 保守召回门禁——只在新 calibration 上选择

建议预注册绝对阈值、最大返回数和 Top-1/Top-2 分差网格。默认优先比较“最多 1 条”和“最多 2 条”，避免把三个高分实体片段都送入 Agent。参数只能由新 calibration 选择，再锁定应用于未见 test；不得复用本节最优的 0.01/0.02 作为既定答案。

### D. 二阶段重排——A～C 不足时再评估

当前 Sentence Transformers Adapter 只使用 BGE-M3 dense 向量，不能对 query-document 对进行 cross-encoder 重排。使用 BGE-M3 的其他能力会引入新的推理路径、依赖、输出/索引契约和显存证据，不属于最小修复；额外本地 reranker 则需要独立模型选择、不可变 revision、许可证核对、文件白名单、额外磁盘与显存预算。现阶段不下载、不安装，也不预设其准确大小或许可证结论。

推荐顺序为 **A + B → 新 calibration 选择 C → 未见 test**。只有该路线仍不能满足未见 Gold，才单独规划 D。无需向量数据库或外部 Embedding API。

## 8. 证据边界

- 本报告可以证明现有分数重叠、rank-4 漏召回、阈值/Top-N 裁剪的局限，以及安全预过滤有效；
- 本报告不能证明 A、B、C 在未见数据上有效；
- 现 15 条场景已经被用于根因诊断，任何后续“在这 15 条上提升”都只能是开发结果；
- 新策略只有在新的、运行前冻结的 holdout Gold 上通过，才可获得新的 P3 准入证据；
- 合成 Gold 仍不是产品准确率或真实玩家收益。
