# M5 双岗位作品集证据清单

## 证据分级

| 等级 | 含义 | 使用方式 |
|---|---|---|
| 已证明工程事实 | 自动测试、事件重放、子进程恢复或冻结接口能够重复验证 | 可直接写入项目经历，但要保留范围限定 |
| 单次真实模型案例 | 在固定提交、模型、预算和次数下保存的真实结果 | 只能写“单次案例观察到”，不能写成功率 |
| 合成评测结果 | 冻结 Gold、Fake Embedding 或架空文本上的指标 | 用于证明评测方法和安全边界，不等于玩家效果 |
| 尚未验证 | 没有真实用户、规模或生产环境证据 | 明确列为限制，不写入量化成果 |

## 不能宣称的内容

- 不能把 P4d 单次闭环写成 DeepSeek 的正式成功率；
- 不能把 M4/M4.5 合成 Gold 指标写成玩家收益、游戏质量或真实语义准确率；
- 不能声称语义长期记忆已进入正式玩法；
- 不能声称生产级并发、远程部署、备份恢复或长期稳定运行已经验证；
- 不能声称完成网页、游戏引擎界面、自适应教学、Reflection 或多 Agent；
- 不能编造真实用户留存、满意度、教学收益、Token、成本或延迟。
