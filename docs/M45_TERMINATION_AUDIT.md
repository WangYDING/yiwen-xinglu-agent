## V1 语义记忆的产品状态

从本审计起，V1 语义向量记忆遵守以下发布边界：

1. 默认关闭；
2. 仅作为实验功能；
3. 不进入正式 Agent Prompt；
4. 允许显式启用 shadow mode，只记录经过权限过滤后“本来会召回什么”；
5. shadow 结果不得改变 Agent 消息、工具集合、行动、课程、玩家状态或病例状态；
6. shadow 失败不得伪装成空历史，也不得阻断不依赖语义记忆的正式玩法；
7. 只有取得真实多病例轨迹、重新冻结验证方案并获得单独授权后，才可重新立项验证 Prompt 注入。

不再继续本轮 BGE 运行、阈值调优、reranker、模型替换、向量数据库或合成题库扩张。若未来重启，它是新的验证工作，不回写本次终止结论。
