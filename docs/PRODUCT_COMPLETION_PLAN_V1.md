# 《问道医途》产品完成计划 v1

> 状态：实现顺序冻结；R1 已完成（2026-08-11）
>
> 适用范围：M0～M6 历史工程之后的新产品实现主线。历史提交、实验、退出审计和成熟度结论保持不变。

## 不变的产品边界

- 玩家亲自调查、诊断和处置；导师观察、教学、提示、师评并在规则允许时表达传承判断。
- 病例、能力、关系、课程、考试、权限和传承的关键状态只由确定性规则与领域事件修改。
- LLM 只能读取权限过滤后的公开视图并生成受约束表达或建议，不能直接写关键状态。
- DoctorAgent 自动解题只用于 Fake 演示、回归、验收与受控模型评测，不代表正式玩家体验。
- M4.5 语义向量记忆继续默认关闭；未通过后续门禁前不得进入正式 Prompt、行动或状态。

## 实现顺序

```text
R1：长期状态与确定性成长底座
→ R2：导师教学闭环
→ R3：三病例教学与结构化记忆
→ R4：考试、权限与传承
→ R5：六病例和医馆入口
→ R6：产品验收与发布准备
```

该顺序是模块依赖调整，不改变 ADR-054 冻结的产品主题和角色分工。

## R1：长期状态与成长底座

**状态：已完成。** 实现与验证边界见 [`R1_APPRENTICESHIP_GROWTH.md`](R1_APPRENTICESHIP_GROWTH.md)。

### 范围

- 唯一跨 Episode `ApprenticeshipState`；
- 六项产品能力：察形、问因、验物、辨证、施治、守则；
- 亲近、信任、认可三维关系；
- 来源可追溯的结构化成长证据；
- 连续长期领域事件；
- 原子 JSON 存储、事件重放、退出恢复和显式协调；
- 病例完成后，从已提交病例事件和最终公开结果产生确定性成长；
- 完成结果和 CLI 展示本次成长及安全长期视图。

### 硬边界

- `ApprenticeshipState` 是跨 Episode 成长的唯一权威来源；病例 Session 的技能/关系字段只是兼容快照或执行输入。
- 不从模型自然语言、拒绝动作、未提交动作、隐藏真相、隐藏门槛或未发现线索产生成长事实。
- R1 状态不影响病例答案、评分规则、行动权限或 Agent Prompt。
- 不调用或实现 MentorAgent、MentorAction、教学、考试、晋级、权限、传承或正式语义记忆。

### 退出条件

玩家完成“旧纸伞与失约书生”的确定性正确轨迹后，至少一项能力和一个关系维度发生有来源、可解释、可重放的变化；重复完成或协调不重复增长，退出重启后结果一致。相同规则必须适用于当前全部三个病例，不允许病例专用应用分支。

## R2：导师教学闭环

- MentorProfile、MentorAgent 和 MentorAction；
- 课程布置、一次有界提示和结构化师评；
- 导师读取并解释 R1 的公开成长状态；
- 导师不得直接修改能力、关系或其他权威状态。

## R3：三病例教学与结构化记忆

- 三病例教学标签和过程评价维度；
- 弱点识别与补课推荐；
- 来源可追溯的结构化长期记忆；
- 跨病例历史反应；
- 基于确定性规则自适应选择下一课程。

## R4：考试、权限与传承

- 教学阶段和正式考试；
- 重考与补课；
- 权限层级；
- 一条能力、关系、考试与承诺共同约束的完整传承链。

## R5：六病例和医馆入口

- 按教学主线改造现有三案并新增三案；
- 医馆主循环与普通用户交互入口；
- 展示成长、关系、课程、师评、考试和传承状态。

## R6：产品验收

- 自动验收；
- 真实模型受控验证；
- 预注册真人试玩；
- 发布准备与最终边界复核。
