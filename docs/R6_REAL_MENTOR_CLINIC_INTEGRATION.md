# R6-P2b 真实导师医馆离线装配

状态：离线装配与 Mock 验证完成；真实医馆烟雾和真人试玩均未执行。

## 运行边界

`xuanyi-clinic` 显式支持 `off`、`fake`、`deepseek`。默认仍为 `fake`；API Key 的存在不会自动启用真实模式。`deepseek` 必须同时提供 `--confirm-paid-run`、大于 0 且不超过 `0.05 CNY` 的 Decimal 预算和既有存档目录。`off` 与 `fake` 不导入或初始化付费传输，DoctorAgent、AgentAction、病例工具和 MCP 工具不进入此链路。

真实模式当前只为五个已有 CommunicationPlan 提供模型表达：初次课程与提示、错误诊断后的补课解释、考试失败解释、传承拒绝解释、传承授予解释。病例后师评、课程完成总结和其他没有正式计划的交互继续使用确定性文本。模型只能改写公开语言；病例、成长、关系、课程、考试、权限、传承和结构化记忆仍由规则层决定。

## 预算、恢复与安全

进程共享一个 `ClinicMentorBudgetState`：授权预算、已确认费用、未核对预留、基础与修复请求计数、冻结状态及原因写入存档目录中的本地账本。每个基础请求与唯一一次公开修复分别预留最大费用，再按 usage 结算。重启同一存档目录会恢复账本；改变授权预算必须使用新的受控运行目录。双玩家共享运行预算，但上下文按玩家单独从公开权威状态投影。

教学质量失败最多修复一次，仍不完整则显示确定性 fallback 并允许游戏和后续独立表达继续。协议、修复后契约、安全、答案泄漏、越权、替玩家行动、模型漂移、usage 缺失、费用不可核对、超时或预算不足会冻结真实导师；冻结后不再调用传输，只显示非技术性提示与确定性 fallback，已经提交的游戏状态不回滚。

持久化日志仅含随机本地运行 ID、交互类型、模型、首次/修复/fallback、Token、延迟、已确认费用和停止类别，不保存 API Key、供应商请求 ID、完整 Prompt、完整响应、玩家自由文本、隐藏状态、答案或精确门槛。

## 离线入口

```powershell
xuanyi-clinic --mentor-mode deepseek --budget-cny 0.05 --dry-run
```

dry-run 只打印模型、thinking、冻结价格快照、预算、五类交互、fallback、存储类别和 loopback 地址；不读取 Key，也不发起网络请求。

```powershell
xuanyi-clinic --mentor-mode deepseek --confirm-paid-run --budget-cny 0.05 --state-dir <目录>
```
